# Handwritten Digit Recognizer

This project is a simple graphical application to recognize handwritten digits using a pre-trained MNIST model.

## ✨ Features
- Draw a digit directly on the canvas.
- Load an image from your computer.
- Recognize digits in real-time using your webcam.
